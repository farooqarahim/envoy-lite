# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) verbatim. By participating — as a contributor, issue reporter, or reviewer — you agree to uphold it.

## Reporting

Report unacceptable behaviour privately to the maintainer at farooqarahim@gmail.com. All reports are reviewed and handled with discretion. Retaliation against good-faith reporters is itself a violation.
